# Correcting the basin weights of pooled chains: what can be guaranteed

Follow-up to `report_20261004_1625.md`, same branch (`ccr-79b8eb7e-96dy4t`). Question: pooled independent
chains converge to basin-of-attraction weights; can this be corrected, with guarantees under
reasonable assumptions, and are the helper functions in place? The standing rule I applied: no estimator
without a statement of what is guaranteed (finite sample or asymptotic) and a derivation or proof;
anything else is labelled a diagnostic. The full ledger is `theory.md`.

## Answer

1. **Why pooling fails (proved, trivial).** Chains confined to the basin they start in have a pooled
   limit `sum_m b_m pi_m`, with `b_m` the probability of landing in basin `m`. It equals the posterior
   iff `b_m = pi(A_m)` for all `m`. Adding chains cannot change it (exact example: 160 chains, total
   variation 0.31 from the exact merge-pattern masses, which are 0.52, 0.30, 0.10, 0.08; the pooled
   weights were 0.22, 0.32, 0.22, 0.22 and 0.03 on a pattern with exact mass about zero).
2. **No correction exists from the chains' own samples.** Something has to link the modes. The
   two principled links are a tempering path to a reference one can sample exactly (the prior), or moves
   that cross between modes. I built the first in two forms and did not build the second.
3. **There is an estimator with an exact finite-sample guarantee** (`smcMDI()`, `smcReplicates()`):
   with a fixed schedule, exact prior draws and `pi_beta`-invariant moves, the weighted sum is *exactly
   unbiased* for the unnormalised posterior and the evidence estimate is unbiased, for any number of
   particles and without any mixing assumption. The ratio estimator (weighted mode masses, weighted
   similarity matrix) is consistent as the number of independent runs grows, **with any fixed number of
   particles per run**. Proved in Lean 4 for annealed importance sampling; with resampling it is Del
   Moral (2004, Thm 7.4.2) and I confirmed it in exact rational arithmetic (never/always/ESS-triggered
   resampling, multinomial and systematic, N = 2 and 3).
4. **But its variance is unbounded in principle and, in the example, ruinous.** The tempering path
   from prior to posterior has a sharp transition. With the exact masses as a reference:

   | method (3000 particles unless stated) | masses of the four patterns | ESS |
   |---|---|---|
   | exact | 0.522, 0.296, 0.099, 0.083 | |
   | SMC, adaptive schedule, 300 particles | 0.73, 0.13, 0.04, 0.07 | 264 |
   | SMC, adaptive schedule | 0.82, 0.01, 0.00, 0.17 | 2670 |
   | SMC, adaptive, finer steps (cess 0.99) | 0.80, 0.13, 0.06, 0.01 | 2884 |
   | SMC, fixed schedule | 1.00, 0, 0, 0 | 1579 |
   | AIS (no resampling) | 0.24, 0.49, 0.19, 0.05 | 5.7 |
   | AIS, 20,000 particles | 0.01, 0.02, 0.00, 0.75 | 1.6 |

   With resampling the masses are wrong and unstable while the ESS looks healthy (a founder effect: the
   few lineages that cross the transition first fix the patterns of the whole population). Without
   resampling the weights are unbiased and useless (ESS 1.6). So **the guarantee is real and the
   estimator is not usable on this problem**, which I will not dress up. ESS cannot detect the
   resampled failure; `smcWeightDiagnostic()` (Pareto k-hat, Vehtari et al. 2024) applies to unresampled
   runs only.
5. **Starting above the prior (`beta_start`)** keeps the path inside the ordered phase, and it did
   move the masses toward the truth (0.43, 0.32, 0.13, 0.13 from `beta* = 0.7`; `beta* = 0.999`, i.e.
   independent chains, gave 0.18, 0.25, 0.23, 0.28; at `beta* = 0.8` the masses moved 0.30 to 0.40
   as start sweeps went 300 to 2000). **No guarantee** for this: it is a conditional procedure. If the
   start were exactly `pi_{beta*}` it is Theorem 3; for a start with law `mu_0` the bias of a bounded
   functional is at most `B prod R_k sum|mu_0 - pi_*|` (proved in Lean), and the total-variation error of
   the start is what no output can reveal. I kept the option, documented it as conditional, and emit a
   message when it is used.
6. **Tempered chains** (previous report) remain the only tool that moved the cold chain between modes to the
   exact masses (12 pooled runs, TV 0.012; single runs 0.06 to 0.28), but their guarantee is the
   asymptotic one the plain chain also has (Harris ergodicity from positive conditionals, argued in
   `theory.md`, not formalised); finite-time statements are not available, and the round-trip
   prediction failed (0 to 3 observed against about 900).

So, for the question as posed: **a correction with a genuine (unbiasedness) guarantee exists and is
implemented; in the hard regime its variance defeats it; every route that works in the example rests on
an assumption of mixing that I can state but not certify.** A certificate would need couplings of the whole
sweep to bound the distance to stationarity (Biswas, Jacob and Vanetti, 2019), which I did not build.

## Helper functions now in the package

`smcMDI`, `smcReplicates`, `combineSMC`, `smcSE` (jackknife over independent runs), `smcWeights`,
`smcDiagnostics`, `smcWeightDiagnostic`, `weightedPSM`, `weightedConsensus`, `smcPosterior`, `resampleSMC`,
`smcAsChain`, `compareRuns` (also for tempered chains), and from before `ptLadder`, `tuneLadder`,
`adaptLadder`, `ptDiagnostics`. Diagnostics (`smcDiagnostics`, `smcWeightDiagnostic`, `compareRuns`,
`ptDiagnostics`) are labelled as having no guarantee in their documentation. `weightedConsensus` uses `salso`
to search for a partition that minimises the estimated expected loss; the estimate of the loss is
consistent, the search is heuristic, as in `processMCMCChain`.

## Limits and what I did not do

* Supported: complete data, `G`/`MVN`/`C`, no outlier component; ensembles also need unsupervised views.
  Memory grows with the number of particles times the data; particles run in sequence.
* Mode-jumping moves (split-merge in the style of Jain and Neal, 2004) would link the modes inside a
  single chain with an exact Metropolis-Hastings correction and might be the better fix; not built. The
  acceptance ratio for a restricted-Gibbs proposal is delicate and I would not ship it without an exact
  test like the ones above.
* The Harris-ergodicity proposition is argued from the form of the conditionals (positivity), not
  proved formally; the exact theorem numbers in Tierney (1994) were not re-checked.
* The jackknife standard error is justified asymptotically in the number of runs; with 8 runs in an
  example with an unbounded-variance weight it carries no assurance.
